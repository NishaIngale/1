# 1. 📊 Zomato Sales Report Analysis (Power BI)

This repository contains a comprehensive Power BI dashboard analyzing Zomato sales data. The report uncovers key business insights related to revenue performance, customer behavior, and product trends.

🎯 Project Objective

The main goals of this sales analysis are to:

- Track overall sales and revenue trends
- Identify high-performing categories and cities
- Understand customer order patterns
- Enable data-driven decision-making through visual insights

> Feel free to explore the PBIX file using Power BI Desktop for interactive filtering, drill-downs, and visual storytelling.

📊 Tools Used

- Power BI Desktop – for report creation and visualization
- DAX – for custom calculations and KPIs
- Data Cleaning – (if applicable) in Power Query
